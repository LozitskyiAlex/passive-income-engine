# Niche decision

## Selected first niche

Construction and home-project calculators.

## Why this niche

1. A recent open-source calculator generator documents a live construction calculator site with 12 calculators, showing that the static calculator pattern can be applied to this niche. 
2. A recent independent side-project report describes a woodworking and home-project calculator site using client-side calculations and Amazon affiliate monetization. This is a self-reported case study, not a forecast.
3. Construction calculations have clear inputs and outputs, so the core utility can run entirely in the browser.
4. Related products have natural commercial intent: lumber, concrete, drywall, paint, flooring, tools, measuring equipment and safety equipment.
5. The niche can be expanded vertically without creating thousands of near-duplicate pages.

## Initial scope

Build a focused construction calculator toolkit with 10 genuinely different calculators:

1. Concrete volume
2. Concrete bags
3. Gravel volume
4. Mulch volume
5. Paint quantity
6. Flooring quantity
7. Tile quantity
8. Drywall sheets
9. Board feet
10. Material cost

The first version will target English because the addressable search market is larger. Spanish can be added after the English version is technically stable.

## What we will not do

We will not mass-generate pages for every city, keyword permutation or product name.

We will not scrape Google results.

We will not copy supplier descriptions.

We will not use AI to invent formulas.

We will not add affiliate links before the tool itself works.

## Validation plan

The first milestone is technical validation: all calculators must produce deterministic results and pass tests.

The second milestone is search validation using Search Console after deployment.

The third milestone is monetization validation through contextual affiliate opportunities and, only when traffic exists, advertising.

Google's current spam policy explicitly warns against scaled pages that exist mainly to manipulate rankings. The product therefore needs to provide a useful calculation on every calculator page.
