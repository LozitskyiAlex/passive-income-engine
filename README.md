# Passive Income Engine

A zero-cost, data-driven engine for building useful static web products.

## Principles

1. No paid APIs
2. No paid hosting
3. No database or VPS
4. Prefer public data sources with permitted access
5. Use automation for collection, normalization, generation, testing, and deployment
6. AI is optional and batch-oriented, not required per visitor
7. Monetization is added only after a useful product and traffic path exist

## Architecture

Public data sources -> collectors -> normalized data -> optional AI enrichment -> static pages -> deployment -> organic traffic -> monetization

## Planned components

* Python source adapters
* Data normalization and validation
* Optional local Ollama enrichment
* Static site generation
* SEO metadata and sitemap generation
* GitHub Actions automation
* Cloudflare Pages deployment

## Current stage

The repository contains the engine foundation. The first profitable niche will be selected using evidence from search demand, competition, available public data, automation potential, and monetization options.
